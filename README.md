# ☕ Starbucks Beverage Dashboard | Power BI

## 📌 Project Overview

The Starbucks Beverage Dashboard is an interactive Power BI project designed to analyze beverage data and present meaningful insights through data visualization. It helps explore beverage categories, pricing, and product-related trends to support data-driven decision-making.

## 🎯 Project Objectives

* Analyze beverage data across different categories.
* Compare product prices and beverage characteristics.
* Identify patterns and trends using interactive visualizations.
* Present key insights through an easy-to-understand dashboard.

## 🛠️ Tools & Technologies

* **Power BI** – Dashboard development and data visualization
* **Power Query** – Data cleaning and transformation
* **DAX** – Measures and calculations (where applicable)

## 📊 Key Features

* Interactive dashboard visuals
* Beverage category analysis
* Product and pricing comparisons
* Easy-to-use visual filters and slicers
* Clear presentation of data insights

## 💡 Key Learnings

* Developed practical skills in Power BI dashboard creation.
* Practiced data visualization and analytical thinking.
* Learned to present data in a structured and interactive format.

## 📁 Project File

* `Starbucks Dashboard.pbix` – Power BI dashboard file

## 🚀 How to Use

1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the dashboard visuals and interact with available slicers and filters.
